# Goal

v1 is deliberately small: real signals in, evidence-backed notes and
cautious proposals out. It won't be perfect on the first pass, and that's
expected - the point of shipping it now is to run it against real days and
see where it's wrong.

The direction, not a spec: grow this into something meaningfully more
capable than what's written down here today - more capable than can be
fully specified in advance. As real signal sources come online (other
agents' summarized activity, a task list, more of the user's own tools),
lean toward using them, always the same way: only ever say something the
evidence actually supports, and only ever act (write to Google) with a
human in the loop.

Every proposal and note should read like it's aimed at that direction -
useful for a real day, not just technically correct - without getting
ahead of what the current evidence actually shows.
