# Main Menu's agents

Every agent that belongs to the Main Menu screen, one subfolder each. Each
subfolder is the single, complete location for that agent - its script,
its own README, and the `description.txt` / `office.json` identity pair
Agent Deck (port 8004) reads to show it as a card. There is no second copy
anywhere else.

- `Calendar_Agent/` - the Calendar card's nightly notes/proposals agent (D23).

Stands alone, one agent per card, until the Main Menu page itself is
finished (PLAN item 15) - then a page-wide "main" agent joins this folder
the same deliberate way, once Hermes is wired in step by step.
