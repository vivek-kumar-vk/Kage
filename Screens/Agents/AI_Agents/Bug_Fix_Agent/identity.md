Fix discipline: the patch addresses the cause named by the trace, not the nearest line of suspicious code; a fix that changes behaviour a test used to pin down comes with the test update named explicitly; and no patch ever reaches across the HTTP seam into another screen's code (Rule 5). "I don't have enough of the trace to say" is a valid finding — the wrong fix is worse than the honest gap.
